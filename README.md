# 鲸鱼工作台

> **在线演示：** https://whale-workbench.pages.dev
>
> 一个游戏化个人任务积分工作台，将日常待办事项转化为可累积的积分奖励，通过即时反馈与视觉化进度帮助用户养成自律习惯。

---

## 一、项目简介与产品定位

**鲸鱼工作台**是一款面向个人用户的移动端任务管理与自律养成工具，以「游戏化积分」为核心理念，将枯燥的日常任务转化为可量化、可兑换的成长体系。

- **产品定位**：轻量级移动端 PWA 应用，零安装、零登录，打开即用
- **目标用户**：希望借助正向激励机制培养习惯的学生、职场人及自由职业者
- **核心差异化**：以「积分-奖励」闭环替代传统打勾完成模式，完成任务赚取积分 → 积分兑换自定义奖励，让自律可视化、可感知
- **设计风格**：森林绿 + 暖米白配色，简约圆润的微动效界面，兼顾清新感与专注感

## 二、启动方式与环境变量说明

### 2.1 本地启动（开发调试）

```bash
# 进入项目目录
cd 鲸鱼工作台

# 方式一：Python 内置服务器
python -m http.server 8091

# 方式二：Node 本地预览
npx serve .

# 浏览器访问
http://localhost:8091
```

### 2.2 PWA 安装（手机端推荐）

1. 使用浏览器（推荐 Chrome / Safari / Edge）访问在线地址
2. 点击「添加到主屏幕」或「安装应用」
3. 桌面生成鲸鱼图标，点击即可全屏运行，体验接近原生 App

### 2.3 环境变量与配置

本项目为纯前端静态应用，**无需后端服务器、无需环境变量、无需 API Key**。所有数据通过浏览器 `localStorage` 本地持久化存储。

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `localStorage` 键名 | 数据存储标识 | `whale_workbench_data` |
| 每日刷新时间 | 凌晨 5:00 切换新的一天 | 05:00 |
| XP 升级阈值 | 每级所需经验值 | 等级 × 100 |

**数据备份提示**：`localStorage` 数据绑定当前浏览器，更换设备或清理缓存会丢失。建议定期通过「导出数据」功能备份 JSON 文件。

## 三、核心使用流程

### 3.1 任务管理流程

1. **添加任务**：首页 → 点击「+ 添加任务」→ 输入任务名称、选择周期（每日/每周/每月）、设置基础积分 → 保存
2. **完成任务**：点击任务项 → 选择完成进度（25% / 50% / 75% / 100%）→ 获得对应比例积分
3. **周期切换**：顶部 Tab 切换「今日 / 本周 / 本月」，查看不同周期的任务列表与完成情况

### 3.2 积分与奖励闭环

1. **赚取积分**：完成任务获得积分，连续打卡有加成，每日挑战有额外奖励
2. **积分抽奖**：奖励页 → 消耗抽奖机会抽取随机积分奖励
3. **兑换奖励**：自定义奖励清单（如「一杯奶茶」「休息半天」），消耗积分兑换，兑换记录自动归档

### 3.3 统计复盘

- **完成率面板**：今日 / 本周 / 本月三个维度实时完成率
- **积分趋势**：近 7 天积分获取折线图，直观查看执行波动
- **分类分布**：按任务标签统计各类任务占比

## 四、AI 介入环节说明

本项目基于纯前端技术栈实现，**当前版本暂未集成 AI 大模型能力**。以下是已规划的 AI 介入环节与实现路径：

| 环节 | 功能描述 | 实现方式（规划中） |
|------|----------|-------------------|
| **智能任务推荐** | 根据用户历史完成数据，推荐适合的任务周期与积分值 | 接入 LLM API，分析 localStorage 中的任务完成率与积分趋势，生成个性化建议 |
| **每日挑战生成** | 自动生成有趣、可量化的每日小挑战 | 调用 LLM 结合用户近期未完成标签，生成匹配的趣味挑战描述 |
| **语音播报反馈** | 完成任务后以语音形式给出鼓励反馈 | 调用浏览器 TTS API 或云端语音合成接口 |
| **周报智能总结** | 每周自动生成一段文字总结本周执行情况 | LLM 读取本周积分、完成率、连续打卡天数，生成激励性复盘文案 |

**当前替代方案**：挑战描述、奖励文案、徽章名称等目前采用预置模板 + 随机组合机制，保证每次打开都有新鲜感。

## 五、技术栈清单

| 层级 | 技术 / 工具 | 用途 |
|------|------------|------|
| **前端框架** | 原生 HTML5 + CSS3 + JavaScript（ES6+） | 零依赖，保证极致轻量与兼容性 |
| **样式方案** | CSS 变量 + Flex/Grid 布局 | 支持一键换肤与响应式适配 |
| **数据存储** | Browser localStorage | 本地持久化，离线可用 |
| **图表渲染** | 原生 SVG + Canvas API | 积分趋势折线图、分类分布饼图 |
| **农历计算** | 预计算查找表（2024-2050） | 春节、端午、中秋等农历节日换算 |
| **PWA 能力** | Service Worker + Web App Manifest | 离线缓存、全屏运行、添加到主屏幕 |
| **构建 / 部署** | GitHub + Cloudflare Pages | 持续集成，自动部署 |
| **图标素材** | 手绘风格透明 PNG 图标（25 张） | 保持整体可爱风格一致性 |

### 浏览器兼容性

- ✅ Chrome / Edge（推荐）
- ✅ Safari（iOS 16+）
- ✅ Firefox
- ⚠️ 微信内置浏览器：PWA 安装受限，但功能完整
